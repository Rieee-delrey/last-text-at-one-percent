The funniest final text message a phone sends at one percent battery, in the voice of the dying phone itself. One message, under 200 characters, and nothing else.

> 1% left. I have read every message you were too scared to send, and I am sending them all now. Starting with your ex. Goodbye.

## Run

```sh
python3 main.py   # writes /output/entry.txt (126 chars)
```

`main.py` asserts the 1–200 character gate and verifies the file by reading it back byte-identical before exiting.
